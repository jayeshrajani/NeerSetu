### Automated page-text check (all rows)

`scripts/verify_pdf_pages.py` (pypdf 6.20.0) extracted the text of each cited page, read `source_page` as a **1-based PDF viewer page**, and searched for a numbered line with the printed parameter label followed by the printed pre/during/after tokens.

- Parameter lines (site × year × festival × parameter groups): exact match **507**, whitespace-insensitive match 1, not found 0, inconsistent page 0.
- The one whitespace-only match is Bairagarh 2025 Ganesh pH: the PDF prints `* *` in the after column; the CSV records `**`.
- Rows whose viewer page is therefore marked text-verified: **1524 of 1524**. The app links these with `#page=N`.
- Limitation: a text match proves the printed tokens occur on that page; when two tables on a page share identical values (e.g. `0.03 0.03 0.03`), it does not by itself prove table→site attribution. The pages show no separate printed page numbers, so viewer page = report page for citation purposes.
